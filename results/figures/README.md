# Figures

The figures in this directory are generated by `scripts/analyze_results.py`.

The primary statistical analysis uses the **600 measured per-second samples** stored in:

```text
data/processed/analysis.csv
```

Regenerate the processed data and all figures with:

```bash
python3 scripts/prepare_analysis.py
python3 scripts/analyze_results.py
```

## Primary figures

The analysis generates:

- boxplots by Linux distribution;
- mean ± standard-deviation bar charts;
- histograms for the main frequency-distribution variables;
- temporal profiles across sample positions 1–10.

These figures use all 600 measured observations.

## Filtered active-phase analyses

The tenth sample of each measured run can represent the FFmpeg termination phase.

For additional exploratory analysis, the filter:

```text
sample <= 9
```

creates an active-phase subset containing **540 observations**, with 90 observations per distribution.

The following figures are generated from this subset:

- `filtered_active_process_cpu_percent.png` — CPU usage of FFmpeg by distribution during the active phase;
- `filtered_active_system_memory_used_mb.png` — system-memory usage by distribution during the active phase.

Corresponding descriptive statistics are stored in:

- `data/processed/subset_active_cpu_by_distribution.csv`;
- `data/processed/subset_active_memory_by_distribution.csv`.

## Aggregated analysis

The script also aggregates system-memory usage by Linux family using all 600 observations.

Generated figure:

- `aggregate_system_memory_by_family.png`.

Corresponding data:

- `data/processed/aggregate_system_memory_by_family.csv`.

## Language

All visible chart titles, axis labels and legends are generated in Portuguese for use in the final academic report.

Legacy run-level figure names from the previous 60-observation analysis are removed automatically to avoid mixing statistical units.
